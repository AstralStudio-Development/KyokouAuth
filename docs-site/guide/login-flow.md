# 玩家的登录流程

## 正版玩家

零操作。

```
连接 → 握手 → 进入世界
```

服务端向客户端发送加密请求，客户端用其会话令牌向 Mojang 确认，服务端向会话服务器复核后放行。玩家看到的就是原版登录画面。

首次登录会绑定名字与 Mojang UUID。之后改名，握手会带来新名字，旧名字释放。

## 微软玩家（无 Java 版）

```
连接 → Limbo → 完成设备码 → 重连 → 进入世界
```

**1. 进入 Limbo**

玩家被允许进入世界，但冻结在原地：无法移动、交互、拾取、掉落或使用命令。屏幕上显示提示与链接。

**2. 完成验证**

点击聊天栏中的链接（或访问 `microsoft.com/link` 输入短码），在微软页面完成登录。

服务端每 5 秒轮询一次结果，超时 300 秒。

**3. 重连**

验证成功后需要重新连接一次。这是因为验证期间玩家使用的是临时 UUID，绑定完成后才确定最终身份。

之后同一 IP 的登录在会话有效期内免验证。

## 失败的情况

| 情况 | 结果 |
|---|---|
| 客户端声称的名字被 Mojang 持有 | 断开，提示使用官方启动器 |
| 设备码超时 | 断开，提示重连 |
| 微软账户名与客户端名字不符 | 断开，提示使用自己的名字 |
| Mojang 不可达 | 断开，不降级到离线 UUID |

认证失败一律断开。没有"降级放行"的路径。

## 旁观者视角

Limbo 中的玩家对其他玩家是可见的（站在出生点或原地），只是不能行动。需要完全隐藏的话请配合其他插件。
